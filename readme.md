
# Proyek CV Pribadi Django

## Deskripsi
Aplikasi CV pribadi berbasis web menggunakan Django dan Bootstrap.

## Fitur
- Menampilkan profil pribadi
- Menampilkan keahlian
- Menampilkan riwayat pendidikan
- Menampilkan proyek
- Mengelola data melalui Django Admin
- Menampilkan foto profil

## Teknologi
- Python
- Django
- SQLite
- HTML dan CSS
- Bootstrap

## Cara Menjalankan
1. Aktifkan virtual environment.
2. Instal Django jika belum tersedia:
   pip install django
3. Jalankan migrasi:
   python manage.py migrate
4. Jalankan server:
   python manage.py runserver
5. Buka http://127.0.0.1:8000/

## Admin
Untuk mengakses /admin/, buat akun administrator dengan:
python manage.py createsuperuser
